# Pratham Rao — Robotics × AI Portfolio

A responsive personal portfolio built with React, Vite, plain CSS, Framer Motion, Three.js, React Three Fiber, Drei, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Vite prints a local URL, usually `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

## Customize

- `src/App.jsx`: portfolio content, social links, projects, education, skills and contact section.
- `src/components/RobotScene.jsx`: the procedural 3D robot arm scene.
- `src/index.css`: visual system, layouts, responsive styling and animations.
- `index.html`: page title and SEO description.

## Before publishing

1. Check all project links and replace GitHub profile links with specific repositories when available.
2. Add project screenshots, demos and verified results as each project is ready.
3. Add your photo in the hero/about area if you still want a portrait; this starter uses the 3D scene as the visual anchor.
4. Confirm the exact official college and degree naming you want shown publicly.
5. Test the site on a phone and run `npm run build`.

Project descriptions are intentionally cautious and can be expanded with your real implementation details. No awards, work experience or metrics are fabricated.
